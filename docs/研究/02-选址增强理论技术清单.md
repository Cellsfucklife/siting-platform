# 选址模型的增强层：可结合的理论与技术清单

> 定位：第一份《选址模型全景综述》回答"有哪些模型"；这一份回答"**还能往上加什么**"。
> 读法：每一条都给三样——**是什么（内核）** / **做了什么（嵌进选址流程的哪一步）** / **优化了什么（相对裸模型的增量）**。

---

## 0. 先看清裸模型的天花板

上一份综述里的八大族，无论多精细，都卡在三个地方：

| 天花板 | 表现 | 后果 |
|---|---|---|
| **① 假设太干净** | 需求是常数、距离是直线/静态、容量是硬阈值、成本是线性 | 算出的"最优"一到真实路网和真实时段就失真 |
| **② 只有一方在决策** | 需求方是"必须被服务的点"，没有选择权、没有反应 | 建了没人用（快递柜）、建了没人来（驿站） |
| **③ 世界是静态的一张图** | 节点建完不动，需求不演化，竞争不出现 | 三年后就过时；无法回答"网络会长成什么样" |

所以增强层分三类：**补假设（不确定性科学）**、**补人（行为与博弈）**、**补动态（复杂系统与计算）**。

## 一、补决策结构：把"一方算最优"变成"多方博弈出均衡"

### 1.1 博弈论 / Stackelberg 双层规划

- **是什么**：把一个决策拆成上下两层——上层（企业/政府）选点，下层（用户/加盟商/其他快递企业）在既定布局下做自利选择，下层的最优反应构成上层的约束。
- **做了什么**：把"需求"从常数改写成"下层对上层决策的响应函数"。末端场景里，下层通常是居民在「上门 / 驿站 / 智能柜 / 无人车接驳」之间的**离散选择**（logit / Huff / 嵌套 logit）。
- **优化了什么**：把"覆盖率"换成"**实际使用率**"。裸覆盖模型说"5 分钟内有柜 = 被服务"，双层模型会说"5 分钟内有柜，但排队 3 分钟，只有 62% 的人愿意来自提"，于是点位与格口数会自己收敛到"建得少但用得满"。
- **落地要点**：logit 的效用函数要能估——用问卷/SP 调查或历史取件行为（上门 vs 自提）标定；否则退化成拍系数。

### 1.2 合作博弈：Shapley 值 / 核仁 / 成本分摊

- **是什么**：当多个主体共用一张网络（多家快递共用驿站、共用无人车运力、政企共建）时，用合作博弈的解法把"共同省下的钱"分掉。
- **做了什么**：先算"各自单干总成本 − 联盟总成本 = 联盟收益"，再用 Shapley 值（按边际贡献）或核仁（按稳定性）分配。
- **优化了什么**：优化的是**方案的可执行性**，不是几何位置。协同网络方案最常见的死法是被问"凭什么我的件要补贴他的线"——Shapley 分配 + 个体理性/联盟理性验证，等于给方案加了"能签得下来"的证明。
- **你们的加分点**：主题就是"协同网络"，把收益分配算一遍，比画一张四层拓扑图有说服力得多。

### 1.3 机制设计 / 拍卖（VCG、逆向拍卖、任务打包）

- **是什么**：设计规则让自利参与者说真话、并按规则被调度。
- **做了什么**：用于**众包运力与闲置运力**的接入——把末端订单打包成标的，让骑手/社区代收点/无人车运营方竞价，VCG 定价保证激励相容。
- **优化了什么**：优化**参与率与单价**。选址模型默认"运力是可调用的"，机制设计回答"以什么价格、多快能调到"。它把"运力"从一个外生常量变成一个可被激励影响的内生变量——正好治"运力决策失真"。

### 1.4 数据产权博弈 + 联邦学习（见 4.1）

- **是什么**：多家企业/政府各持有一部分数据（订单、路网、人口、信令），在不共享原始数据的前提下联合训练模型。
- **做了什么**：把"需求预测"和"候选点评分"改成横向联邦训练，各方只上传梯度/参数。
- **优化了什么**：优化**协同的合法性**。这是"跨企业协同"绕不开的合规前提（个人信息保护法、数据二十条）。方案里写一句"采用联邦学习实现跨主体联合建模，原始数据不出域"，是把技术方案变成可立项方案的关键一句。

## 二、补假设：从"确定"到"知道自己有多不确定"

### 2.1 分布鲁棒优化 DRO（Wasserstein / KL 球）

- **是什么**：既不像随机规划那样信任一个精确概率分布，也不像经典鲁棒那样假设最坏情况必发生；而是在"与经验分布距离不超过 ε 的一族分布"里取最坏期望。
- **做了什么**：用历史订单直接构造经验分布，半径 ε 由样本量/置信水平定，把内层 max 对偶化成可解形式。
- **优化了什么**：优化**样本效率与保守度的平衡**。两阶段随机规划要"情景集 + 概率"，鲁棒要"不确定集"，DRO 只要"历史样本 + 一个半径"，对"新小区、无历史、只有同类小区数据"这种场景特别合适。
- **文献状态**：DRO 设施选址/人道物流已有成熟论文与求解路径（[Wasserstein DRO 人道物流](https://www.sciencedirect.com/science/article/pii/S2214716024000216)、[DRFL](https://scholar.google.de/citations?citation_for_view=NPDmx4MAAAAJ:Y5dfb0dijaUC&hl=ja&sortby=pubdate)）。

### 2.2 极值理论 / 情景生成 + 压力测试

- **是什么**：用 EVT（POT、GPD）刻画需求尾部，生成"百年一遇的大促"情景，而不是从历史里抽样。
- **做了什么**：给"大促峰值"造出可解释、可复现的情景集，灌进随机/鲁棒模型，或直接对候选方案做压测。
- **优化了什么**：优化**峰值能力配置**。常规做法用"日均件量 × 峰值系数"，系数是拍的；EVT 让峰值系数有统计依据，也让答辩时的"双 11 三倍量"不再是断言。

### 2.3 贝叶斯优化 / 代理模型（Kriging、GPR、随机森林代理）

- **是什么**：目标函数算一次很贵（一次仿真跑几十分钟）时，用少量采样拟合一个廉价代理，再用采集函数（EI/UCB）决定下一个点。
- **做了什么**：把"仿真优化"从"枚举 + 试算"变成"20 次仿真内找到近优"；还能顺带给出不确定带（哪些点位的绩效预测本身不可靠）。
- **优化了什么**：优化**可算性**。多层网络 + 仿真校验的最大障碍是组合爆炸，代理模型是唯一能在方案周期内闭环的手段。

### 2.4 机会约束与 CVaR

- **是什么**：不追求"期望最优"，而是控制"超载/超时的概率"或"最差 5% 的损失"。
- **做了什么**：把服务水平写成 `P(超时) ≤ α` 或 `CVaR_α(成本) ≤ B`。
- **优化了什么**：优化**风险表达**。评审问"你这套网络在极端情况下会怎样"，机会约束/CVaR 是唯一能给出量化回答的语言。

## 三、补空间与行为：把"平面上的点"换成"有重力、有惯性的城市"

### 3.1 时空地理学：时空棱镜 / 可达性时空约束

- **是什么**：Hägerstrand 的时间地理学——个体在"时间预算 × 空间可达"的棱镜内活动。
- **做了什么**：算出居民"几点在哪个可步行/骑行范围内"，据此判定"柜/驿站"对他是否**真的可用**，而不是地图上直线 300 m。
- **优化了什么**：优化**有效覆盖**。这是把"覆盖"从几何概念升级为行为概念的最轻量方法：不改模型结构，只改覆盖矩阵 `a_ij` 的生成方式。对"一柜难求"与"柜前冷清"并存的现象解释力极强。

### 3.2 空间交互模型（重力模型 / Huff / 最大熵）

- **是什么**：用"吸引力 ÷ 阻抗"表达需求如何在多个设施间分配，由最大熵原理可严格导出。
- **做了什么**：替代"最近点全归它"的硬指派，让需求按概率分流；也用于**竞品分流**（周边已有菜鸟驿站、丰巢）。
- **优化了什么**：优化**需求分配的真实度**。裸 p-中值假设"每个需求点只去最近的那个"，现实是"近的贵、远的便宜就分流"。改这一处，同一套点位能算出差别很大的载荷。

### 3.3 复杂网络 / 韧性工程（级联失效、渗流、N-k）

- **是什么**：把配送网络当图，度量度分布、聚类系数、介数、连通性；用渗流与级联失效模型测"打掉几个节点会瘫痪"。
- **做了什么**：识别**关键枢纽**（介数高的中转点）、评估"单点故障"、给出冗余度指标。
- **优化了什么**：优化**结构鲁棒性**。这是给"四层网络"的最直接增强：不是问"应该几层"，而是问"删掉任意一层/任意 k 个节点，覆盖率掉多少"——把层数从"设定"变成"必要性证明"。对"结构缺口"这一诊断，这就是量化工具。

### 3.4 空间统计：Moran's I、GWR/MGWR、地理加权

- **是什么**：检验空间自相关（需求是否成片）、用地理加权回归建模**参数本身随空间变化**。
- **做了什么**：证明"北京各区的件量-人口关系不一样"，从而拒绝"一个全市统一系数"。
- **优化了什么**：优化**标准的空间异质性**。你们要立的那把"区分社区的尺子"，最硬的立论就是 MGWR 显示回归系数在空间上显著漂移——所以标准必须分区、分圈层。这比任何定性描述都有说服力。

### 3.5 社区发现与空间约束聚类（Louvain / Leiden / SKATER / max-p）

- **是什么**：图上自动找"内部联系紧、外部联系松"的簇；max-p-regions 保证每个区满足最小规模且空间连续。
- **做了什么**：替代"按行政街道划区"，用订单流/路网流自动划配送责任区。
- **优化了什么**：优化**分区质量**。行政边界与物流流不重合是末端效率损失的大头；用流量聚类划出的区，天然满足"区内短、区间少"。

### 3.6 中心地理论 / 生活圈 / 15 分钟城市

- **是什么**：Christaller 的中心地等级体系（服务等级越高、间距越大）+ 国内《社区生活圈规划指南》的 15 分钟步行圈。
- **做了什么**：给"几层、每层多大服务半径"提供**理论先验与政策口径**，而不是从数据里硬拟合。
- **优化了什么**：优化**层级的合法性**。四层网络如果只有数据支撑会被问"凭什么是四层"；接了中心地理论 + 生活圈指南，就是"理论层级 + 政策口径 + 数据校核"三重支撑。

### 3.7 城市标度律（Bettencourt scaling）

- **是什么**：城市指标与人口呈幂律（`Y ∝ N^β`），基础设施类 β≈0.85，社会经济类 β≈1.15。
- **做了什么**：用少量城市样本拟合"件量-人口-面积"标度关系，外推到新城市/新区。
- **优化了什么**：优化**可迁移性**。方案要"可推广到其他超大城市"，标度律就是那个迁移参数——给出"人口翻倍，末端节点该乘 1.8 还是 2.2"的定量答案。

### 3.8 空间句法 / 路网形态学

- **是什么**：用整合度、选择度等拓扑指标度量街道的"可达潜力"。
- **做了什么**：在候选点打分里加入"这条街的拓扑位置"，解释为什么某些路口天然适合做接驳点。
- **优化了什么**：优化**候选点质量**。属于精细化加分项，成本低、观感好。

## 四、补计算：让上面的东西真的算得出来

### 4.1 联邦学习 / 隐私计算（同 1.4）

- 横向联邦做需求预测，纵向联邦做"企业订单 × 政府人口 × 社区画像"的联合特征。
- 优化：**跨主体数据可用性**，同时满足合规。

### 4.2 图神经网络 GNN

- **是什么**：在路网/订单图上做消息传递，捕捉"邻接即相关"。
- **做了什么**：预测**网格级/社区级分时段件量**，直接产出覆盖模型的权重 `h_i`；也可做"节点嵌入"给候选点打分。
- **优化了什么**：优化**需求侧的精度与空间一致性**。传统时序模型逐点预测，忽略邻区 spillover；GNN 天然带空间耦合。

### 4.3 深度强化学习（DRL）

- **是什么**：把布局/调度当序贯决策，学一个策略而非求一个解。
- **做了什么**：① 动态选址（随需求迁移开/关/迁移点位）；② 与调度联动（点位定了，车怎么跑）；③ 多期建设顺序。
- **优化了什么**：优化**动态适应性与在线决策**。华东师大团队已有深度强化学习做空间优化的系统性成果（[介绍](https://geo.ecnu.edu.cn/2a/bf/c42636a666303/page.htm)），可作为方法论依据。
- **诚实提醒**：DRL 在"一次决策、静态"的选址上不占优（MIP 更可解释），它的价值在"反复决策"与"嵌入式实时"。

### 4.4 逆强化学习 / 偏好学习

- **是什么**：从已有行为反推背后的目标函数。
- **做了什么**：拿京东现有 427 个配送站的实际布局，反推"它当初在优化什么"（租金权重、覆盖权重、时效权重）。
- **优化了什么**：优化**基准的公平性**。有了逆推的隐含权重，你的"优化方案"与"现状"才是同一把尺子上的比较，而不是"我的模型 vs 他们的直觉"。这是一个成本低、观感极好的差异点。

### 4.5 大模型（LLM）用于建模与仿真

- **是什么**：用 LLM 把自然语言的需求描述转成数学规划模型、生成求解代码、或扮演行为主体。
- **做了什么**：① **自动建模**（LLM4OR 一类工作已有系统性梳理，[LLM4OR](https://github.com/xianchaoxiu/LLM4OR)；国内高校也在开"基于大语言模型的数学规划建模"专题，[东南大学讲座](https://em.seu.edu.cn/2026/0415/c29365a562278/page.htm)）；② **LLM 多智能体仿真**——让 LLM 扮演不同社区居民，模拟"愿不愿意自提/接不接受无人车"，产出比 logit 更丰富的选择分布；③ 方案解释与敏感性叙述。
- **优化了什么**：优化**建模速度与行为仿真的丰富度**。注意边界：LLM 不替代求解器，也不保证最优性，它的位置是"前端建模 + 行为生成 + 后端解释"。

### 4.6 分解算法：Benders / 列生成 / 分支定价 / ADMM

- **是什么**：把大规模 MIP 拆成主问题 + 子问题迭代求解。
- **做了什么**：让"四层网络 + 容量 + 时间窗 + 不确定情景"这种真实规模的问题在可接受时间内求出最优或近优。
- **优化了什么**：优化**可解规模**。方案里如果只有"用遗传算法求解"，会被质疑没有最优性保证；有 Benders 下界，就能报 gap。

### 4.7 量子退火 / QUBO 建模

- **是什么**：把组合优化写成二次无约束 0-1 形式（QUBO），用量子/量子启发退火器求解。
- **做了什么**：两级设施选址已有量子退火求解的实现与研究（[Quantum annealing for the two-level facility location problem, FGCS 2025](https://www.sciencedirect.com/science/article/pii/S0167739X25002560)）。
- **优化了什么**：优化**求解时间**（在特定规模区间）。属于"前瞻性亮点"，适合放在"技术展望"而非主线——除非你们真能跑出对比实验，那就成了硬创新。

### 4.8 数字孪生 + 离散事件仿真 + ABM

- **是什么**：把路网、订单到达、设备、人员建成可运行的虚拟系统，方案在里面跑。
- **做了什么**：校验优化解在动态环境下的真实绩效；ABM 进一步让"居民/骑手/无人车"成为有规则的智能体，观察涌现行为（如某个柜被挤爆、某条线空驶）。
- **优化了什么**：优化**从"纸面最优"到"运行可行"的落差**。这是"运力决策失真"的最终解药：优化模型给候选，仿真给真相。

## 五、补治理与可持续：让方案能立项、能算绿色账

### 5.1 因果推断（DID / 合成控制 / 断点回归 / uplift）

- **是什么**：在无法做随机实验时，从观测数据里识别"政策/措施的真实效应"。
- **做了什么**：评估北京 2021 年首批无人配送车路权放开、非高峰轨道交通运快递试点等措施的**净效应**（对照未放开区域）。
- **优化了什么**：优化**政策论证的可信度**。方案要建议"扩大路权"，就得有"上一轮放开带来多少效率提升"的因果估计，而不是相关性。

### 5.2 LCA 生命周期评价 + 碳核算（GHG Protocol 范围一/二/三）

- **是什么**：标准化的碳排放计量框架，范围三覆盖上下游（含配送）。
- **做了什么**：给每个方案算"单件末端碳排"，把碳做成目标函数第三维或约束。
- **优化了什么**：优化**绿色化的可核查性**。"减碳 20%"如果没有核算边界与因子来源，就是口号；有了范围三口径 + 排放因子表，就是可审的数。

### 5.3 ESG / 政策一致性映射

- **做了什么**：把方案指标与《北京市有效降低全社会物流成本实施方案》《十五五规划纲要》条款逐条对齐。
- **优化了什么**：优化**评审口径命中率**。属于"非技术但决定分数"的一层。

## 六、补演化：回答"三年后这张网长什么样"

### 6.1 系统动力学

- **是什么**：用存量-流量、反馈回路刻画长期演化。
- **做了什么**：把"件量增长 → 单点超载 → 新建点 → 成本上升 → 提价/自提率上升 → 件量分流"写成回路，跑 3–5 年。
- **优化了什么**：优化**时间维度**。选址模型给的是"某一年的最优解"，系统动力学给的是"演化路径与拐点"——比如"第 3 年必须加建第二层"。

### 6.2 情景规划（壳牌法：2×2 轴）

- **做了什么**：把"无人车政策 × 件量增速"交叉成四个情景，在每个情景下重算网络，找"四情景都不难看"的稳健方案。
- **优化了什么**：优化**战略稳健性**。比"给一个最优解"高一个层级，且极易在答辩中讲清楚。

## 七、横向迁移：别的领域的成熟技术可以直接借

| 来源领域 | 可借什么 | 迁移到末端配送的对应物 |
|---|---|---|
| 通信基站选址 | 覆盖 + 容量 + **干扰**三维约束 | "干扰"→ 同业竞争分流与自家网点互相蚕食 |
| 电动汽车充电桩 | 排队 + 绕行成本 + 电网容量 | 无人车换电站/充电桩与接驳点**共址**选址 |
| 应急设施（救护车） | 概率覆盖 MEXCLP、公平性、冗余 | 大促峰值下的"期望覆盖"、应急保供点 |
| 医院/学校选址 | 2SFCA 可达性、公平性度量 | 社区服务均等化论证、弱势社区优先 |
| 军事后勤 | 鲁棒/韧性、N-k 失效 | 网络抗中断能力 |
| 供应链金融/网络设计 | 多级库存-选址联合 | 前置仓 + 网格仓的层间库存分配 |

## 八、怎么用：六个组合拳（对应三个瓶颈）

| 组合 | 组成 | 治哪个瓶颈 | 方案中的角色 |
|---|---|---|---|
| **标准内生拳** | p-中心反解 R + MGWR 证空间异质 + 时空棱镜生成覆盖矩阵 | 标准缺位 | 主线（第 1 项任务） |
| **结构必要性拳** | 复杂网络介数识别枢纽 + 级联失效测 N-k + 中心地/生活圈定层级 | 结构缺口 | 主线（第 2 项任务） |
| **行为校准拳** | 双层规划 + logit 自提选择 + 空间交互分流 + ABM 校验 | 运力决策失真、建了没人用 | 主线（第 3 项任务） |
| **协同可签拳** | 合作博弈 Shapley 分收益 + 机制设计定接入价 + 联邦学习保合规 | 协同落地 | 加分/差异化 |
| **稳健兜底拳** | DRO 或两阶段随机 + EVT 情景 + CVaR + 仿真压测 | 大促与不确定性 | 校验层 |
| **演化前瞻拳** | 系统动力学跑 3–5 年 + 四情景规划 + 逆强化学习校准基准 | 方案的时效性 | 收尾/展望 |

**一条硬原则**：增强层不是越多越好。评委只认"**每个技术都对应一个被量化改善的指标**"。建议主线只用 3 个（标准内生、结构必要性、行为校准），其余 3 个作为校验与展望各占半页。堆 15 个名词的方案，通常一个都没算实。
