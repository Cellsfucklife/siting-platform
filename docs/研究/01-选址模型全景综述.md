# 选址模型全景综述：数据 → 依据 → 操作 → 产出

> 用途：为「面向超大城市的末端配送协同网络规划」提供模型选型底稿。
> 统一读法：任何选址模型都可以拆成四段——**灌进去什么数据（Input）**、**依据什么假设与目标（Basis）**、**做了什么运算（Operation）**、**吐出什么结论（Output）**。看懂这四段，模型之间就只剩参数差异。

---

## 0. 一句话把握全部模型

所有选址模型都在解同一个问题：

```
在一个"候选在哪 + 谁服务谁 + 花多少"的可行域里，
把某些原始数据换算成一个或几个可加总的指标（成本、距离、覆盖率、公平性、碳排），
然后求这个指标的极值（或排序）。
```

差别只在于三件事：
1. **可行域的形状**——平面连续（重心法）、离散候选集（覆盖/中值）、层级网络（轴辐/两级）；
2. **目标函数的形式**——求最小（成本型）、求最大（覆盖型）、求最平（公平型）、求最稳（鲁棒型）；
3. **谁在做决策**——单一决策者（企业）、两级决策者（企业 + 用户行为）、多主体（政府/企业/居民）。

## 1. 总体谱系（八大族）

| 族 | 代表模型 | 一句定位 | 典型适用 |
|---|---|---|---|
| A 连续型 | 重心法（Weber）、交叉中值、多设施重心迭代 | 不分候选、直接在平面上找点 | 单仓/单点粗选、初步定址 |
| B 离散覆盖型 | 集合覆盖 SCP、最大覆盖 MCLP、p-中心、概率覆盖 MEXCLP | 用"服务半径/时效"定义覆盖，追求覆盖最多或用的点最少 | 快递柜、驿站、应急、公共服务 |
| C 离散成本型 | p-中值、UFL/CFLP（容量约束）、分配模型 | 用"距离×需求量"或"固定投资+运输费"算总成本 | 分拨中心、配送站、仓网 |
| D 层级网络型 | 两级/多级选址、轴辐（Hub-and-Spoke）、枢纽中值 | 先定层级再定节点，处理干线-支线-末端 | 全国-区域-城市-社区多层网络 |
| E 耦合型 | LRP 选址-路径、2E-LRP、选址-库存 LIP | 选址和排线一起解，避免"选完才发现跑不动" | 末端配送、无人车接驳 |
| F 不确定/动态型 | 两阶段随机、鲁棒优化、机会约束、CVaR、多期动态 | 需求是分布/情景而非定值，方案要抗波动 | 大促、新小区、政策变动 |
| G 多准则评价型 | 加权因素法、AHP、熵权-TOPSIS、模糊综合评价、ELECTRE/VIKOR | 不可量化的因素（政策、地价、协同）变成可比较分数 | 候选地最终排序、方案比选 |
| H 数据与智能驱动型 | GIS 空间分析、需求预测+优化、强化学习、元启发式、仿真/数字孪生 | 用大数据与算法替代"拍参数" | 城市级网络、动态布局、超大搜索空间 |

## 2. 逐族拆解：数据 / 依据 / 操作 / 产出

### A. 连续型（重心法族）

| 项 | 内容 |
|---|---|
| **数据基础** | 各需求点（客户/社区）的平面坐标（或经纬度）、各点需求量或运量 `w_i`、单位运价 `c_i`；若用交叉中值还需路网走向（曼哈顿距离） |
| **基于什么** | 只有运输成本，且运费与距离成正比；设施可建在平面上任意点；无容量、无固定投资、无时效约束；直线距离近似路网 |
| **操作** | 最小化 `Σ w_i·c_i·d_i(X)`：① 精确解用 Weiszfeld 迭代；② 手工解用"重心公式初值 + 迭代修正"；③ 交叉中值法把 x、y 拆开各自取加权中位数；④ 多设施则先聚类分区，再逐簇求重心 |
| **得到什么** | 一个坐标点（或多簇各一个点）、该点下的最小总运输成本、以及"每点服务范围"的初始划分 |
| **局限** | 点常落在湖面、铁路、封闭小区里 → 必须叠加可建性筛网；对时效、容量、投资完全不敏感；结果对需求点位置极度敏感 |

> 常被当成"先跑一个数看看"，真正的价值是给离散模型提供候选点与初始解。

---

### B. 离散覆盖型（服务标准驱动）

这一族是"末端网络"最贴题的一族，因为它的核心参数就是**服务半径 / 时效阈值**。

| 模型 | 数据基础 | 基于什么（假设与目标） | 操作 | 得到什么 |
|---|---|---|---|---|
| **集合覆盖 SCP** | 候选点集 J、需求点集 I、覆盖矩阵 `a_ij`（由行驶时间 ≤ S 判定）、建设成本 | 需求只要落在阈值内就算"被服务"，容量无限；目标是"用最少的点/最少的钱全盖住" | 0-1 整数规划：`min Σ c_j x_j`，`s.t. Σ_{j∈N_i} x_j ≥ 1` | 最少的设施数量与位置；若不可行，说明标准定得太高 |
| **最大覆盖 MCLP** | 同上 + 预算或点数 p、各需求点权重 `h_i`（人口/订单量） | 资源有限，接受部分覆盖；目标是"给定 p 个点，覆盖的加权需求最大" | `max Σ h_i y_i`，`s.t. y_i ≤ Σ_{j∈N_i} x_j`，`Σ x_j = p` | 首选 p 个点位 + 覆盖率 + **未被覆盖的需求清单（缺口图）** |
| **p-中心 p-Center** | 需求点、候选点、距离矩阵 | 追求"最坏情况最优"——让服务最差的那个点也尽量近（公平性/应急） | `min R`，`s.t. d_ij x_ij ≤ R` | p 个点 + 最大服务距离 R（可直接反推"服务半径标准"） |
| **概率覆盖 MEXCLP** | 同上 + 每个设施/车辆的忙概率 q | 设施会"忙"，覆盖不是恒定的；目标是期望覆盖率最大 | 引入"第 k 个覆盖层"的边际增益 `(1-q)q^{k-1}` | p 个点 + 期望覆盖率曲线（加一个点边际收益多少） |
| **容量约束覆盖** | 覆盖矩阵 + 每个站点容量/格口数/人力上限 | 覆盖之外还要装得下 | 覆盖约束 + 容量约束 + 分配变量 | 点位 + 每个点承接的订单量 + 溢出需求去向 |

**关键点**：`a_ij` 怎么来，决定了模型的"真实度"。低配用直线距离，标配用路网 OD 矩阵（驾车/骑行/步行分别算），高配用**分时段阻抗**（早晚高峰）。末端场景里，"步行 5 分钟能到柜"和"骑行 10 分钟能到驿站"必须是两张覆盖矩阵。

### C. 离散成本型（成本驱动）

| 模型 | 数据基础 | 基于什么 | 操作 | 得到什么 |
|---|---|---|---|---|
| **p-中值 p-Median** | 需求权重 `h_i`、候选点、路网距离矩阵 `d_ij`、点数 p | 总运输成本/总里程最小，不设服务半径；容量默认无限 | 0-1 规划 `min Σ h_i d_ij x_ij`，每个需求恰好指派一个设施 | p 个点 + 指派关系 + 总(加权)距离；适合"总配送里程最少"的站网 |
| **UFL / CFLP** | 候选点固定开设成本 `f_j`、单位运价、容量 `Q_j`、需求量 | 固定投资 + 变动运输费之和最小；开不开由模型决定（不是给定 p） | 混合整数规划：`min Σ f_j y_j + Σ c_ij·流量`，`s.t. 流量 ≤ Q_j y_j` | 开哪些点、各自吞吐、服务哪些需求、总成本；**可直接做"多建一个点值不值"的边际分析** |
| **多级/两级 UFL** | 两级候选点（分拨/驿站）、干线运价、支线运价、各层容量 | 层级间运价不同，流量逐层汇聚 | 两层流量守恒 + 两层固定成本 | 两层同时开哪些、层间流量分配、层级总成本 |
| **轴辐 Hub-and-Spoke** | 枢纽候选、辐点、干线折扣系数 α、集散成本 | 干线有规模折扣（α<1），走枢纽比直达便宜 | 枢纽中值/枢纽弧模型，含单重/多重指派 | 枢纽选址 + 干线网络拓扑 + 折扣后的总成本 |

> 求解现实：CFLP 是 NP-hard。小规模用 Gurobi/CBC 直接求；中大规模用拉格朗日松弛、Benders 分解；超大规模转元启发式（见 H）。

### D. 层级网络型（超大城市网络必用）

末端配送真正的难点不是"选一个点"，而是"**几层节点、每层几个、层间怎么串**"。代表性做法：

1. **两级选址-分配（2E-LFLP）**：分拨中心 → 社区驿站/柜，两层同时决策。数据要两套运价（干线整车 + 末端电动车/无人车）、两套容量、两套时效承诺。
2. **轴辐式多级网络**：把"城市分拨—区域中转—社区末梢"抽象成 hub 层与 spoke 层，用折扣系数表达规模化运输的经济性。
3. **层级 + 分区**：先把城市划成若干配送区（Voronoi / 泰森多边形 / 聚类 / 行政街道），再在每个区内做单点或双点选址。分区是"降维"手段，也是"责任田"落地手段。
4. **2024—2025 的"移动卫星"变体**：末端接驳点不固定，用无人车/移动柜做"可移动卫星仓"，选址模型里候选点带时间窗与可迁移属性（2E-LRP with mobile satellites）。

**产出**：节点层级结构（层数、每层节点数与位置）、层间连接关系、每层承担的流量与成本，以及"缺一层会怎样"的对照。

### E. 耦合型（选址 + 路径 / 库存）

| 模型 | 数据 | 基于什么 | 操作 | 产出 |
|---|---|---|---|---|
| **LRP 选址-路径** | 候选点、客户点、车辆容量/数量/成本、时间窗 | 选址与路径互相决定，分开算会低估成本 | 两阶段（先选后路）或一体化 MIP；大规模用"聚类 + 路径"启发式 | 选址 + 每条线路 + 车队规模 + 总成本 |
| **2E-LRP** | 两层车辆（干线货车/末端小车）、中转点、卫星点 | 城内大车受限、末端小车效率低，需中转 | 两层路径 + 中转点选址 | 中转点位置 + 两级车队 + 时效达成率 |
| **选址-库存 LIP / LIRP** | 补货周期、安全库存、持有成本 | 少建点省投资但库存与补货成本上升 | 非线性/分段成本线性化 | 点位 + 各点库存策略 + 总成本 |
| **绿色/碳约束变体** | 排放因子、能耗、车重载重 | 成本之外加碳目标或多目标 | 多目标（ε-约束 / 加权 / Pareto） | 成本-碳排 Pareto 前沿，用于"绿色化"论证 |

### F. 不确定性与动态型

| 模型 | 数据 | 基于什么 | 操作 | 产出 |
|---|---|---|---|---|
| **两阶段随机规划** | 需求情景集（多情景 + 概率，可从历史订单/大促数据抽样） | 先建（一阶段），再看情景补运营（二阶段） | 情景平均 + 样本平均近似 SAA | 一组"不管哪种情景都不太差"的点位 + 各情景期望成本 |
| **鲁棒优化** | 需求区间/不确定集（box、budget） | 只关心最坏情况，不依赖概率 | 对偶转化（Soyster / Bertsimas-Sim） | 最坏情景下仍可行的方案 + "保守代价" |
| **机会约束 / CVaR** | 需求分布或尾部样本 | 控制"超载/超时"的概率或尾部损失 | 分布近似 + 线性化 | 满足给定服务水平的最小成本方案 |
| **多期动态选址** | 分年度需求增长、租金变化、可开可关 | 建了不能随便拆，要分阶段投 | 多期 MIP（含开关成本） | 每期开哪些、何时开、何时扩 |
| **时变/排队覆盖** | 分时段需求、服务台数量、服务时长 | 需求随时间涨落，能力有限会排队 | 排队论（M/M/c 近似）+ 覆盖约束 | 分时段点位与人力配置 |

> 用在哪：大促爆量、新交付小区从零起量、无人车政策放开的不确定性，都属这一类。评审最认这一块——"你的方案为什么不脆弱"。

### G. 多准则评价型（把说不清的因素变成分数）

| 项 | 内容 |
|---|---|
| **数据基础** | 指标体系得分：地价/租金、建筑面积与装卸条件、路网可达性与限行、覆盖人口与订单密度、竞品/同业密度、政策与补贴、电力与消防条件、扩展余量、协同度（与现有 427 个配送站的距离） |
| **基于什么** | 存在大量不可货币化因素；决策者对指标有偏好；候选点有限且已经初筛过 |
| **操作** | ① 建指标体系（目标层—准则层—指标层）；② 定权重——主观法（AHP 判断矩阵、德尔菲）或客观法（熵权、CRITIC、主成分）；③ 归一化（极差/向量）；④ 合成排序——TOPSIS（贴近度）、模糊综合评价（隶属度）、ELECTRE/VIKOR（优序关系）、灰色关联 |
| **得到什么** | 候选地块的综合得分与排名、各指标贡献分解、权重敏感性分析 |
| **局限** | 权重主观、无法保证"资源约束下的最优"、不能回答"少建一个点损失多少" |

**正确用法是组合**：MCDM 做**粗筛与解释**（把 200 个候选缩到 30 个，并说清为什么），优化模型做**定量最优**（在 30 个里选 9 个并算成本）。只有 MCDM 的方案会被质疑"没有最优性"；只有优化的方案会被质疑"不接地气"。

### H. 数据与智能驱动型（现在的主流增量）

| 子类 | 数据基础 | 基于什么 | 操作 | 产出 |
|---|---|---|---|---|
| **GIS 空间分析** | POI、路网、建筑轮廓、行政区划、人口栅格、订单点位 | 空间关系可计算：邻近、可达、聚集 | 缓冲/叠加分析、网络分析（服务区、OD 成本矩阵）、核密度估计热点、泰森多边形划分责任区、两步移动搜索法 2SFCA 算可达性、GIS 内嵌位置-分配求解 | 需求热力图、可达性地图、覆盖缺口图、候选点集、服务区划分 |
| **需求预测 + 优化（predict-then-optimize）** | 历史订单、时段、天气、促销日历、POI、手机信令、小区画像 | 需求不是给定常数，而是可预测的时空场 | 时空图神经网络/梯度提升/Transformer 预测网格需求 → 作为 `h_i` 灌进覆盖或中值模型 | 未来分时段需求面 + 据此确定的点位与容量 |
| **端到端 / 决策聚焦学习** | 同上 + 历史决策结果 | 预测误差应按"对决策的影响"加权，而非按绝对误差 | 决策聚焦训练（SPO/Dfl）、可微优化层 | 直接输出点位，且对预测偏差更稳 |
| **强化学习选址** | 状态（需求分布、现有网络、成本）、动作（开/关/迁移）、奖励（成本/时效） | 布局是序贯决策，且环境动态 | 深度强化学习（DQN/PPO/图强化学习）训练策略；华东师大团队已有深度强化学习做空间优化的系统成果 | 动态布局策略（可随需求迁移持续调整），而非一次性静态方案 |
| **元启发式** | 目标函数可算即可 | 问题 NP-hard、规模大、多目标 | 遗传算法、NSGA-II/III、粒子群、模拟退火、禁忌搜索、变邻域；多目标出 Pareto 集 | 近优解集 + Pareto 前沿（成本 vs 时效 vs 碳） |
| **仿真优化 / 数字孪生** | 路网、交通流、订单到达过程、设备参数 | 解析模型刻画不了拥堵、排队、随机到达 | 离散事件仿真 + 优化循环（或代理模型），数字孪生做"方案预演" | 方案在动态环境下的真实绩效：时效达成率、空驶率、峰值能力、瓶颈环节 |

**这就是 2024—2025 的方向**：从"一次算一个最优解"转向"**预测 → 优化 → 仿真校验 → 动态调整**"的闭环。方案里如果只有静态 MIP，会被认为停在 2015 年。

## 3. 一张对照总表（数据 / 依据 / 操作 / 产出）

| 族 | 最小数据需求 | 核心假设 | 代表算法 | 直接产出 | 最怕被问什么 |
|---|---|---|---|---|---|
| 重心法 | 坐标 + 需求量 + 运价 | 直线距离、无容量、无投资 | Weiszfeld 迭代 | 一个坐标点 | "这点能建吗？" |
| 集合覆盖 | 覆盖矩阵 + 候选点 | 阈值内即覆盖、容量无限 | 0-1 规划 | 最少点位 | "盖住了但装得下吗？" |
| 最大覆盖 | 覆盖矩阵 + 权重 + p 或预算 | 允许漏覆盖 | 0-1 规划 | p 点位 + 覆盖率 | "为什么 p 取 9？" |
| p-中值 | 距离矩阵 + 权重 + p | 成本最小、无半径 | 0-1 规划/启发式 | p 点位 + 指派 | "时效怎么保证？" |
| CFLP | 固定成本 + 容量 + 运价 | 线性运输成本 | MIP/拉格朗日 | 开关 + 流量 + 总成本 | "需求波动怎么办？" |
| 两层/轴辐 | 两层候选 + 两套运价 + 容量 | 干线有规模折扣 | MIP/分解算法 | 层级结构与流量 | "层数为什么是四层？" |
| LRP/2E-LRP | 候选点 + 客户 + 车队参数 + 时间窗 | 路径与选址耦合 | 一体化 MIP / 聚类+路径 | 点位 + 线路 + 车队 | "路径真的跑得通吗？" |
| 鲁棒/随机 | 情景集或不确定集 | 概率或区间已知 | SAA / 对偶转化 | 稳健方案 + 代价 | "情景从哪来？" |
| MCDM | 指标打分表 | 权重可表达偏好 | AHP/熵权/TOPSIS | 排序与得分 | "权重凭什么这么定？" |
| GIS | 空间数据 + 路网 | 空间可达可计算 | 网络分析/2SFCA/Voronoi | 缺口图/服务区 | "只是画图，没有优化？" |
| 预测+优化 | 多源时序数据 | 需求可预测 | 时空 GNN + MIP | 动态需求面 + 点位 | "预测误差怎么传导？" |
| 仿真/孪生 | 运行参数 + 到达过程 | 系统行为可离散化 | 离散事件仿真 | 绩效指标与瓶颈 | "仿真校验过优化解吗？" |

## 4. 选型决策树（按问题特征挑模型）

```
只有一个设施、只要大致位置？            → 重心法（+ 可建性筛网）
有服务半径/时效红线，要"盖住"？          → 集合覆盖（先看可行）→ 最大覆盖（再看最优）
只问"最少建几个点能达标"？               → 集合覆盖 / p-中心
只问"总成本/总里程最小"？                → p-中值 / CFLP
固定投资和容量都不能忽略？               → CFLP（含开关决策）
有多层节点、层间运价不同？               → 两级选址 / 轴辐
选址和排线必须一起考虑？                 → LRP / 2E-LRP
要用户来自提、存在选择行为？             → 双层规划（上层成本、下层 logit/Huff 选择）
需求不确定、大促爆量？                   → 两阶段随机 / 鲁棒 / CVaR
因素说不清、要可用于答辩解释？           → AHP-熵权-TOPSIS 粗筛 + 优化定量
要回答"空间公平/可达性"？               → 覆盖 + 2SFCA + 泰森多边形
要给出动态、可持续调整的布局？           → 预测 + 优化 + 仿真闭环 / 强化学习
```

## 5. 落到本项目（分拨中心—社区驿站—智能柜—无人接驳点）

**推荐主线：四层网络 + 分层模型 + 统一校验。**

| 层 | 主模型 | 数据 | 关键约束 | 产出 |
|---|---|---|---|---|
| L1 城市分拨 | CFLP / 两级 UFL | 街道级订单量、干线运价、租金、场地 | 容量、时效 24h 承诺 | 分拨数量与位置、覆盖分区 |
| L2 社区驿站/柜 | 最大覆盖 + 容量约束 + 双层规划 | 社区点位、人口与件量、步行/骑行 OD 矩阵、自提意愿 | 服务半径（步行 5 min / 骑行 10 min）、格口数、租金 | 点位 + 承接量 + 社区分类阈值 |
| L3 无人接驳点 | p-中值 / 覆盖 + 时窗 + 可通行路网 | 无人车路权路段、接驳距离、充电/换电点 | 可通行、往返时长、单车周转 | 接驳点位置与数量、单车服务圈 |
| 校验 | 仿真 / 数字孪生 + 鲁棒情景 | 交通流、到达过程、故障率 | 峰值压力、大促情景 | 时效达成率、空驶率、成本-碳 Pareto |

**三个可直接写进方案的"模型级创新点"**：
1. **把"社区分类标准"变成模型输出而非输入**——用 p-中心反解最大服务距离 R、用容量约束反解单点承载上限，从而把"标准缺位"变成"标准内生"。
2. **双层规划刻画"用户愿不愿意来自提"**——上层是企业成本，下层是居民在"上门/驿站/柜/无人车"之间的 logit 选择，避免"建了没人用"。
3. **预测—优化—仿真闭环**——需求面用多源数据预测，优化出点位，仿真校验峰值，形成可复算的参数表，而不是一次性结论。
