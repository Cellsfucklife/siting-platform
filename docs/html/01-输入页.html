原始流水

每行 小区名、日期、件量。平台会拟合「件量 = 截距 + 年趋势 + 周内系数」，把件量换成设计年日均，峰值系数取观测值。

日期认 2025-01-03、2025/1/3、2025年1月、2025。按日才识别周内系数，月系数需要跨度满两年。

运行参数
